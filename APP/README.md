## 📦 交付与技术栈

- **单文件** `index.html`，双击即可在任意现代浏览器运行（手机浏览器全屏体验更佳）
- **Vue 3 + Tailwind CSS + Phosphor 图标 + canvas-confetti**，全部 CDN 引入，零构建、零安装
- 旧版本已归档至 `_archive/`（小星球 v1 / kimi-v3 vanilla 三文件版）

## 🎨 设计系统（固定铁律）

- **暖杏橙**：主色 `#E88B6E` / 辅色 `#F2A988` / 暖金 `#f59e0b`
- 底色 `#F2F2F7`（iOS 浅灰）/ 白卡 / 墨字 `#1C1C1E` / 弱文本 `#8E8E93`
- **液态玻璃 Liquid Glass**：所有卡片与导航均为半透明 + backdrop-blur 磨砂 + 发丝线 + 内高光，背景衬暖杏橙氛围光斑
- 342px 单台真机壳 + 灵动岛 + 真实底部导航；iOS 8pt 间距、44pt 触控目标、按压回弹、Sheet 上滑动效

1. **行动闭环**：打卡/微习惯/课程 → 赚积分 ✨ → 积分兑换养护物资 → 宠物成长
